This module analyzes incoming photographic evidence and produces a forensic risk assessment to help prioritize human analyst review.  This system acts as decision support, not a decision-maker. It does not declare evidence "real" or "fake"—final forensic and legal determinations remain with the human analyst.  ⚙️ Core Feature: Pre-Upload Model SelectionThis module gives the analyst complete control over the forensic evaluation before the image is processed.When submitting an image via the UI or API, you must select a Model Choice to dictate how the AI evaluates the evidence:"All models combined (recommended)"The image is routed through all 5 trained models simultaneously.The system calculates a unified ML Consensus score based on the aggregate results.Why this matters: We treat model disagreement as a highly meaningful signal. If models heavily disagree, the system flags the evidence as ambiguous, indicating it requires immediate human review rather than blindly averaging the score.Specific Model Override (e.g., "forensics_model_v4.joblib")If an analyst already knows the context of the image (e.g., they know it is a filtered selfie or a CIFAKE-style synthetic scene), they can force the dashboard to feature the results of the specific model trained on that exact domain.Safety Guardrail: Even if a specific model is featured prominently, the background Risk Score will still calculate the full ensemble consensus to prevent forensic tunnel vision.📁 Repository StructurePlaintextapp_image.py                          - The application interface (UI + auto API)
